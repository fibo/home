# Task without git

This folder is not a git repository, so `git diff` is not available.

If the `AGENTS.md` file exists in the current folder, read it for instructions.

Execute all commands related to the task using the current folder as working directory.

Before changing any file, show the proposed changes as a unified diff and wait for human approval.
Apply only approved changes.
A new file is shown as a diff against `/dev/null`.

The task is done when the human says so.
